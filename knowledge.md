# A PLACE BEYOND TIME

## Project Identity
A Place Beyond Time is a personal website dedicated to meaningful letters, memories, and experiences.

Live website:
https://cennaandrin.vercel.app/

## Design Direction
Inspired by Rei Ayanami from Neon Genesis Evangelion.

Visual identity:
- Minimalist Japanese aesthetic.
- Pale blue and muted cyan.
- Off-white and cool grey.
- Deep navy typography.
- Solid-color backgrounds.
- Elegant serif headings.
- Clean sans-serif body typography.
- Generous whitespace.

## Design Philosophy
The website should feel like a quiet digital sanctuary.

It should be personal, nostalgic, elegant, and timeless.

Avoid generic romantic website templates.

## Features
- Homepage.
- Personal notes and letters.
- Memory timeline.
- Optional music player.
- English, Indonesian, and Japanese.
- Light and dark themes.
- Responsive layouts.

## Development Rules
1. Always inspect before modifying.
2. Preserve existing functionality.
3. Never delete personal content.
4. Never invent personal memories.
5. Avoid unnecessary dependencies.
6. Keep components reusable.
7. Prioritize accessibility.
8. Test changes before completion.
9. Preserve Vercel compatibility.
10. Never deploy without explicit approval.

## Important
The existing project must be improved, not rebuilt from scratch.
