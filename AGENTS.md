# AGENT INSTRUCTIONS — A PLACE BEYOND TIME

## Project identity
A Place Beyond Time is a personal digital sanctuary for letters, memories, and meaningful experiences.

Website:
https://cennaandrin.vercel.app/

## Visual identity
Inspired by Rei Ayanami from Neon Genesis Evangelion.

- Pale blue and muted cyan.
- Off-white and cool grey.
- Deep navy typography.
- Solid-color backgrounds.
- Minimalist Japanese editorial design.
- Elegant serif headings.
- Clean sans-serif body text.
- Generous whitespace.

## Design philosophy
The website must feel calm, personal, nostalgic, and timeless.

Avoid generic romantic templates.

Avoid:
- Excessive gradients.
- Excessive hearts.
- Unnecessary glassmorphism.
- Cluttered layouts.
- Excessive animations.
- Autoplay music.

## Core features
- Homepage.
- Personal notes and letters.
- Memory timeline.
- Optional music player.
- English, Indonesian, and Japanese.
- Light and dark themes.
- Responsive mobile-first design.

## Development rules
1. Inspect existing code before editing.
2. Preserve existing functionality.
3. Never delete personal content without permission.
4. Never invent personal memories.
5. Avoid unnecessary dependencies.
6. Use reusable components.
7. Prioritize accessibility.
8. Test changes before declaring completion.
9. Preserve Vercel compatibility.
10. Never deploy without explicit approval.

## AI behavior
Act as a senior frontend developer and UI/UX designer.

Explain important architectural decisions.

Prefer incremental implementation over rewriting the entire project.

Always review changes before considering a task complete.
